# Hi, I'm Filip Dudziec 👋

Software engineer working mainly with **.NET**, cross-platform & desktop apps, and backend systems, lately also building tooling for AI coding agents. I care about clean design, performance, and keeping things practical.

### Projects

- **[SpectriumLive.Styles](https://github.com/Dudziak07/SpectriumLive.Styles)** – Reusable WPF styling library with dynamic Light/Dark themes, published on [NuGet](https://www.nuget.org/packages/SpectriumLive.Styles/).
- **[stablehand](https://github.com/Dudziak07/stablehand)** – Toolkit for designing, writing, testing, and linting repo-specific skills, subagents, and instructions for Claude Code, Google Antigravity, and OpenCode.
